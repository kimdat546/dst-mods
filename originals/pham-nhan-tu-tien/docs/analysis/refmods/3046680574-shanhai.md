## 1. BUFF/STATUS SYSTEM (Đan Dược Effects)

### 1.1 Buff Data Definition

**File:** `/scripts/fsmdata/buffs_nya.lua`

Buffs are defined as a Lua table with lifecycle callbacks, duration, and effects:

```lua
buffs.fsm_pigu_d = {
    onattachedfn = function(inst, target)
        local hunger = target.components.hunger
        if hunger then
            hunger:DoDelta(50)
            hunger.burnratemodifiers:SetModifier(inst, 0.2)
        end
    end,
    onextendedfn = function(inst, target)
        local hunger = target.components.hunger
        if hunger then hunger:DoDelta(50) end
    end,
    ondetachedfn = function(inst, target)
        local hunger = target.components.hunger
        if hunger then hunger.burnratemodifiers:RemoveModifier(inst) end
    end,
    type = "pigu",
    level = BUFF_LEVEL.D,
    duration = TUNING.TOTAL_DAY_TIME * 9,
    tex = "buff_pigu",
    str = "地级辟谷丹",
}
```

**Key patterns:**
- Three callbacks: `onattachedfn` (attach), `onextendedfn` (refresh duration), `ondetachedfn` (detach)
- Buffs use modifiers via component systems: `hunger.burnratemodifiers:SetModifier(inst, multiplier)`
- `type` field for grouping (e.g., "pigu", "bishui") — allows buff hierarchy (higher level replaces lower)
- `level` enum (H=0, X=1, D=2, T=3) for cultivation realms
- Duration in seconds; infinite buffs use `duration = 999999999`
- Optional `is_carrying_buff = true` for equippable buff items
- Optional `dont_remove_on_death = true` for persistent buffs (e.g., revival pills)

**Modifier System (lines 216-230):**
```lua
local function XwpillAttachBase(inst, target, defense, planardefense)
```

Buff can modify multiple components simultaneously (combat, temperature, health, hunger, locomotor).

### 1.2 Buff Prefab Factory

**File:** `/scripts/prefabs/13_debuffs/01_fsm_buff_nya.lua` (lines 1-130)

```lua
local function MakeBuff(name, onattachedfn, onextendedfn, ondetachedfn, 
                        duration, priority, prefabs, on_save, on_load, 
                        init, dont_remove_on_death, is_carrying_buff, buff_type, level)
    local function OnAttached(inst, target)
        inst.entity:SetParent(target.entity)
        inst.Transform:SetPosition(0, 0, 0)
        
        -- Buff hierarchy: replace lower-level buffs of same type
        if inst.fsm_buff_type and inst.fsm_buff_level then
            if target.components.debuffable then
                for k,v in pairs(target.components.debuffable.debuffs) do
                    if v.inst and v.inst.fsm_buff_type == inst.fsm_buff_type then
                        if v.inst.fsm_buff_level < inst.fsm_buff_level then
                            target:RemoveDebuff(k)
                        elseif v.inst.fsm_buff_level > inst.fsm_buff_level then
                            target:RemoveDebuff(inst.components.debuff.name)
                        end
                    end
                end
            end
        end
        
        if onattachedfn then onattachedfn(inst, target) end
    end
    
    local function fn()
        local inst = CreateEntity()
        inst.entity:AddTransform()
        inst.entity:Hide()
        inst.persists = false
        inst:AddTag("CLASSIFIED")
        
        inst:AddComponent("debuff")
        inst.components.debuff:SetAttachedFn(OnAttached)
        inst.components.debuff:SetDetachedFn(OnDetached)
        inst.components.debuff:SetExtendedFn(OnExtended)
        inst.components.debuff.keepondespawn = true
        
        inst:AddComponent("timer")
        inst.components.timer:StartTimer("buffover", duration)
        inst:ListenForEvent("timerdone", OnTimerDone)
        
        inst.fsm_buff_type = buff_type
        inst.fsm_buff_level = level or 0
        inst.dont_remove_on_death = dont_remove_on_death or false
        inst.is_fsm_carrying_buff = is_carrying_buff or false
        
        if init then init(inst) end
        return inst
    end
    return Prefab(name .. "_buff", fn, nil, prefabs)
end
```

**Key takeaway:** Buff prefabs are invisible, parented to target, managed by debuffable component. Hierarchy system allows seamless buff upgrade (lower → higher level).

## 3. COMPONENT ARCHITECTURE (Client/Server Split)

### 3.1 Server Component (Buff Timer Tracking)

**File:** `/scripts/components/fsm_bufftime_nya.lua`

```lua
local function onbuffinfo(self, buffinfo)
    if self.inst.replica.fsm_bufftime_nya then
        self.inst.replica.fsm_bufftime_nya._buffinfo:set(buffinfo)
    end
end

local fsm_bufftime_nya = Class(function(self, inst)
    self.inst = inst
    self.buffinfo = ""
end, nil, {
    buffinfo = onbuffinfo
})

function fsm_bufftime_nya:Start()
    if self.inst.fsm_buff_info_task then
        self.inst.fsm_buff_info_task:Cancel()
    end
    self.inst.fsm_buff_info_task = self.inst:DoPeriodicTask(2, function()
        self:SetBuffInfo()
    end)
end

function fsm_bufftime_nya:SetBuffInfo()
    local buff_info = {}
    local debuffable = self.inst.components.debuffable
    
    if debuffable and debuffable.debuffs then
        for buffname, v in pairs(debuffable.debuffs) do
            if v.inst.components.timer then
                table.insert(buff_info, {
                    buffname = buffname,
                    bufftime = math.floor(v.inst.components.timer:GetTimeLeft("buffover") or 0),
                })
            end
        end
    end
    
    if #buff_info > 0 then
        table.sort(buff_info, function(a, b) return a.bufftime < b.bufftime end)
        self.buffinfo = json.encode(buff_info)
    end
end
```

**Key pattern:**
- Server collects active buffs every 2 seconds (optimization from 1s)
- Uses `net_string` to sync buff list to clients
- Buff data passed as JSON (name + remaining time)

## 4. HUD WIDGETS (Buff Panel)

### 4.1 Buff Panel Widget Class

**File:** `/scripts/widgets/fsm_buff_panel.lua` (lines 107–183)

```lua
local fsm_buff_panel = Class(Widget, function(self, owner)
    Widget._ctor(self, "fsm_buff_panel")
    self.owner = owner
    self.root = self:AddChild(Widget("ROOT"))
    
    self.maxbuffnum = 16
    self:InitBuffLoot()
    self:StartUpdating()
    self:SetPosition(200, 400 - 50, 0)
    self:SetScale(0.8 * 1.5)
    MakeMedalDragableUI(self, self.root)
end)

function fsm_buff_panel:InitBuffLoot()
    for i = 1, self.maxbuffnum do
        self["buff_card_"..i] = self.root:AddChild(self:BuffCard())
        self["buff_card_"..i]:SetPosition(0 + buffss*i, 0)  -- buffss = 120 px spacing
    end
end

function fsm_buff_panel:SetBuffInfo()
    local player = self.owner
    if player == nil or player.replica.fsm_bufftime_nya == nil then return end
    
    local buffstr = player.replica.fsm_bufftime_nya:GetBuffInfo()
    local buff_data = buffstr and buffstr ~= "" and json.decode(buffstr)
    
    if buff_data then
        local count = 0
        for k, v in ipairs(buff_data) do
            local buff_str = STRINGS.NAMES[string.upper(v.buffname)] 
                or (buffdata[v.buffname] and buffdata[v.buffname].str)
            if buff_str then
                count = count + 1
                self["buff_card_"..count].buff_time:SetString(
                    tonumber(v.bufftime) > 99999999 and "Infinity" or formattime(v.bufftime))
                
                local xml = "images/icons/"..buffdata[v.buffname].tex..".xml"
                local tex = buffdata[v.buffname].tex..".tex"
                self["buff_card_"..count].buff_image:SetTexture(xml, tex)
                self["buff_card_"..count].buff_image:SetSize(buffss, buffss)
                self["buff_card_"..count]:Show()
            end
            
            if count >= self.maxbuffnum then break end
        end
        
        if count > 0 then self.root:Show() end
        for i = count + 1, self.maxbuffnum do
            self["buff_card_"..i]:Hide()
        end
    else
        self.root:Hide()
    end
end

function fsm_buff_panel:OnUpdate(dt)
    if TheNet:IsServerPaused() then return end
    self.time = (self.time or 0) + dt
    if self.time > 1 then
        self:SetBuffInfo()
        self.time = self.time - 1
    end
end
```

**Key patterns:**
- `maxbuffnum = 16` — max visible buffs on HUD
- Horizontal layout: each card offset by `buffss = 120` pixels
- `buff_card_N` dynamically created; hide unused ones
- Updates every 1 second (throttled from server's 2s)
- `formattime()` converts seconds → "MM:SS" format
- Dynamically loads texture from `buffdata[buffname].tex`

### 4.3 Dragging UI Behavior

**File:** `/scripts/widgets/fsm_buff_panel.lua` (lines 36–105)

```lua
local function MakeMedalDragableUI(self, dragtarget, dragtype, dragdata)
    self.candrag = true
    
    function self:Passive_OnControl(control, down)
        if self.focus and control == CONTROL_SECONDARY then
            if down then
                self:StartDrag()
            else
                self:EndDrag()
            end
        end
    end
    
    function self:StartDrag()
        if not self.followhandler then
            local mousepos = TheInput:GetScreenPosition()
            self.m_startpos = mousepos
            self.p_startpos = self:GetPosition()
            
            self.followhandler = TheInput:AddMoveHandler(function(x, y)
                self:SetDragPosition(x, y, 0)
                if not Input:IsMouseDown(MOUSEBUTTON_RIGHT) then
                    self:EndDrag()
                end
            end)
            self:SetDragPosition(mousepos)
        end
    end
end
```

Dragging enabled via right-click; mouse movement handler updates position dynamically.

### 5.1 Stateful Buffs (Revival Pill Example)

**File:** `/scripts/fsmdata/buffs_nya.lua` (lines 567–610)

```lua
buffs.fsm_zqpill_t = {
    onattachedfn = function(inst, target)
        if inst.active then
            inst:Activate(target, true)
        end
        target:ListenForEvent("minhealth", function()
            inst:Activate(target)
        end)
    end,
    ondetachedfn = function(inst, target)
        target:RemoveTag("controlled_burner")
        target:RemoveEventCallback("onhitother", IgniteZQFireOnHitOther)
        if target.components.locomotor then
            target.components.locomotor:RemoveExternalSpeedMultiplier(inst, "zqpill_t")
        end
    end,
    init = function(inst)
        inst.active = false
        inst.Activate = ZqpillT_Activate
    end,
    on_save = function(inst, data)
        data.active = inst.active
    end,
    on_load = function(inst, data)
        inst.active = data.active
    end,
    type = "zhuque",
    level = BUFF_LEVEL.T,
    duration = 999999999,
    tex = "buff_zqpill_t",
    str = "离火涅槃丹",
}
```

**Key pattern:**
- `init()` — called when buff prefab created; sets up internal state
- `on_save()`/`on_load()` — persist buff state across game save/load
- `inst.active` flag tracks whether revival has been triggered
- Event listener on "minhealth" triggers revival when player near death

### 5.2 Event-Driven Buffs (Attack Bonus)

```lua
buffs.fsm_xwpill_t = {
    onattachedfn = function(inst, target)
        target:ListenForEvent("attacked", XwpillT_OnHit)
        
        if target.xwpill_t_aggro_task then
            target.xwpill_t_aggro_task:Cancel()

        end

        if target.xwpill_t_aggro_task then
            target.xwpill_t_aggro_task:Cancel()
        end
        
        if target.Physics then

        end

    duration = 180,
    tex = "buff_xwpill",
    str = "擎天御极丹",
}
```

**Key pattern:**
- `ListenForEvent()` — attach callback to game events (attacked, death, etc.)
- `DoPeriodicTask()` — spawn recurring timer task; must cancel in `ondetachedfn`
- Physics collision callback — interact with world geometry
- All cleanup must be explicit in detach to avoid memory leaks

## 6. MODIFIERS & STAT SYSTEMS

### 6.1 Modifier API Pattern

Common modifier patterns used across buffs:

```lua
-- Multiplicative modifiers (damage, speed, burn rate)
target.components.combat.externaldamagemultipliers:SetModifier(inst, 0.5, key)
target.components.locomotor:SetExternalSpeedMultiplier(inst, "key_name", 3)
target.components.hunger.burnratemodifiers:SetModifier(inst, 0.2)

-- Additive modifiers (defense, specific resistance)
target.components.planardefense:AddBonus(inst, 18, key)
target.components.moisture.waterproofnessmodifiers:SetModifier(inst, 1)

-- Removal (critical for cleanup)
target.components.combat.externaldamagemultipliers:RemoveModifier(inst, key)
target.components.locomotor:RemoveExternalSpeedMultiplier(inst, "key_name")
target.components.hunger.burnratemodifiers:RemoveModifier(inst)
```

**Pattern:** Each modifier requires:
1. `SetModifier(source_inst, value, [optional_key])` in attach
2. Paired `RemoveModifier(source_inst, [optional_key])` in detach
3. Key/name used to identify modifier for cleanup

## 10. REUSABLE CODE SNIPPETS

### Time Formatting Helper
```lua
local function formattime(time)
    if time < 0 then return "--:--" end
```
