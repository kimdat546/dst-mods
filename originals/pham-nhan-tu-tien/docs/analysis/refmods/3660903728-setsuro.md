# Setsuro Character Mod Analysis (ID: 3660903728)

## Overview
**Setsuro** is a polished custom character mod for Don't Starve Together featuring "Yukishio," an ice-themed fox girl character. The mod demonstrates professional-grade architecture for character systems including skill trees, custom components, replicated state, character-specific items, and modular UI frameworks.

**Key Characteristics:**
- Character name: `setsuro` (avatar name)
- Unique ice/frost themed abilities
- Comprehensive skill tree system (DST skill points)
- Custom energy/resource management component
- Character-exclusive weapons and cosmetics
- Multi-language support (Chinese, English, Russian)

## 2. Custom Character Abilities/Skills

### Multi-Tier Skill System

#### Energy Component (Badge-like resource)
**File:** `/scripts/components/setsuro_energy.lua`

Simple replicable component that syncs energy value to clients:
```lua
-- Line 19-33
local setsuro_energy = Class(function(self, inst)
    self.inst = inst
    self.val = 0                           -- Current energy
    self.max = db.max or 360               -- Max energy (360 default)
end, nil, {
    val = on_val,   -- Setter triggers replica sync
    max = on_max,   -- Setter triggers replica sync
})

function setsuro_energy:DoDelta(delta)     -- Add/subtract energy
    self.val = math.clamp(self.val + delta, 0, self:GetMax())
    if old ~= self.val then
        self.inst:PushEvent("setsuro_energy_changed")
    end
end
```
Used by modular systems: quick-build, attack speed boost, harvest speed.

local function ReticuleTargetFn()
    local player = ThePlayer

    local pos = Vector3()
    for r = LEAP_CONFIG.RANGE - 1, 0, -.25 do
        pos.x, pos.y, pos.z = player.entity:LocalToWorldSpace(r, 0, 0)

## Key Takeaways for Tu-Tiên Mod

### 1. **Modular Architecture is Non-Negotiable**
Setsuro separates concerns across:
- Components (state management)
- Hooks (behavior modification)
- Managers (reusable utilities)
- Stategraphs (animations)
- UI (client-side display)

This prevents spaghetti code and makes debugging trivial.

### 2. **Skill Trees > Hard-Coded Skills**
Use DST's native `skilltree` component system instead of custom progression. It provides:
- Visual branching paths (3 parallel trees here)
- Activation callbacks
- Lock conditions
- Mod compatibility

### 3. **Replica Components Are Essential**
Always create both server and client versions of state (energy, skill cooldowns, level). Use `AddReplicableComponent()` to sync automatically.

### 4. **Config-Driven Balance**
Never hard-code damage values or cooldowns. Central `tuning.lua` table + `modinfo.lua` configuration options allow balance tweaks without code changes. Players can customize difficulty via mod settings.

### 5. **Skin/Avatar Framework is Reusable**
The `AVATAR_SETSURO_API.MakeCharacterSkin()` pattern is designed for reuse. Create a generic version for your mod to simplify adding cosmetics.
