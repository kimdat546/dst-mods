# Move!!Dragonfly Study — Boss AI/Mount/Stategraph Patterns

**Reference mod**: Workshop ID 3670669065 — A complete system for making vanilla Dragonfly mobile, mountable, and rideable with spatial combat awareness.

## 1. Brain/AI Architecture

### 1.1 Custom Brain Class (`dragonfly_mount_brain.lua`)

The mod creates a **specialized behavior tree brain** for mount-specific AI decision-making:

**File**: `scripts/brains/dragonfly_mount_brain.lua:19–560`

```lua
local DragonflyMountBrain = Class(Brain, function(self, inst)
    Brain._ctor(self, inst)
end)

function DragonflyMountBrain:OnStart()
    local inst = self.inst
    -- Priority-based behavior tree root
    local root = PriorityNode({
        GotoLeader,      -- Follow bell leader
        CombatBehavior,  -- Chase/dodge targets
        WaitBellLink,    -- Pause during bell-write
        Follow(...),     -- Follow freely
        Wander(...)      -- Default patrol
    }, 0.1)
    self.bt = BT(inst, root)
end
```

**Key insight**: Uses DST's standard **behavior tree (BT)** with `PriorityNode` + `WhileNode` composition, not a flat state machine. Priorities allow smooth fallthrough to next behavior when conditions no longer match.

### 1.2 Combat Awareness System

The brain tracks **opponent attack patterns and danger ranges dynamically**:

**File**: `dragonfly_mount_brain.lua:237–304` (`WatchTargetCombat` function)

```lua
local function WatchTargetCombat(inst)
    if inst.components.rideable and inst.components.rideable:IsBeingRidden() then
        return  -- Pause AI when mounted
    end
    
    local target = inst.targetmem.target
    local target_combat = target.components.combat
    local time = GetTime()
    local cooldown = target_combat:GetCooldown()
    
    -- Track attack cooldown transitions
    if old_cooldown > 0 and cooldown <= 0 then
        inst.targetmem.resume_cooldown_time = time  -- Ready to attack
    end
    
    inst.targetmem.sgname = sg.currentstate.name
    inst.targetmem.timeinstate = sg.timeinstate
    inst.targetmem.distsq = inst:GetDistanceSqToInst(target)
```

This records:
- **Attack state changes** (via `sg:HasStateTag("attack")`)
- **Historical hit data**: `inst_attacked[sgname]` = {timeinstate, distsq}
- **Attack range estimates** from weapon/physics radius
- **Target invincibility** and cooldown state

### 1.3 Evasion Logic

**File**: `dragonfly_mount_brain.lua:135–209` (`ShouldRunaway` + `IsInDangerRange`)

```lua
local function IsInDangerRange(inst)
    local distsq = inst.targetmem.distsq or 1e6
    local danger_range_sq = GetDangerRangeSq(inst)
    return distsq < danger_range_sq * 1.05  -- ~5% hysteresis margin
end

local function ShouldRunaway(inst)
    local target = inst.targetmem.target
    local really_attacking = inst.targetmem.really_attacking
    
    -- Only flee if:
    -- 1. Target is in danger range AND attacking/about-to-attack
    -- 2. Health < 20%
    -- 3. Target is invincible
    
    if health_percent < 0.2 or really_attacking then
        return true
    end
    return false
end
```

**Stand-still mechanic**: Dragonfly pauses near enemy, waiting for attack animation to end, then approaches—simulating predictive dodging.

### 1.4 Event Hooking Pattern

**File**: `dragonfly_mount_brain.lua:389–414`

```lua
local _SetTarget = combat.SetTarget
combat.SetTarget = function(combat, ...)
    _SetTarget(combat, ...)
    local target = combat.target
    
    if target then
        inst:ListenForEvent("onattackother", inst._ontargetattackother, target)
        inst:ListenForEvent("onmissother", inst._ontargetattackother, target)
        inst:ListenForEvent("onareaattackother", inst._ontargetattackother, target)
        inst:ListenForEvent("invincibletoggle", inst._ontargetinvincibletoggle, target)
        inst:ListenForEvent("onremove", inst._ontargetremove, target)
    end
end
```

Brain hooks `combat.SetTarget()` to attach event listeners when a new target is acquired. This enables **reactive behavior**—the brain updates its target memory in real-time as the enemy swings.

## 2. Mount/Rideable Component

### 2.1 Rideable Setup

**File**: `scripts/prefabs/dragonfly_mount.lua:840–843`

```lua
inst:AddComponent("rideable")
inst.components.rideable.canride = true
inst.components.rideable:SetSaddleable(true)
```

The **rideable component** is created once at setup. Custom rider test enforces:
- Dragonfly must have a saddle (`IsSaddled()`)
- Dragonfly must not be starving (`hunger > 0`)
- Only the saddle owner (or unowned dragonfly) can ride

**File**: `dragonfly_mount.lua:35–60`

```lua
local function PotentialRiderTest(inst, potential_rider)
    if not inst.components.rideable:IsSaddled() then
        potential_rider.components.talker:Say("ANNOUNCE_DRAGONFLY_NEED_SADDLE")
        return false
    end
    
    local hungry = inst.components.hunger:GetPercent() <= 0
    if hungry then
        potential_rider.components.talker:Say("ANNOUNCE_DRAGONFLY_NEED_FOOD")
        return false
    end
    return true
end
```

### 2.3 Mount State Callbacks

**File**: `dragonfly_mount.lua:216–242` (`OnRiderChanged`)

```lua
local function OnRiderChanged(inst, data)
    inst.components.combat:SetTarget(nil)  -- Clear AI target
    local newrider = data.newrider
    inst._rider:set(newrider or inst)  -- Network sync
    
    if newrider == nil then
        -- Delay 5 seconds, then transform to fire if still idle
        inst.transform_normal_task = inst:DoTaskInTime(5, function()
            if not inst.components.rideable:IsBeingRidden() then
                inst:StartTransformNormal()
            end
        end)
    end
end
```

When unmounted, the dragonfly **cancels combat** and can enter rage/fire mode after 5 seconds. This prevents the mount from attacking while riderless.

### 2.4 Flying Mode & Collision

**File**: `postinit/prefabs/player.lua:7–36` (`EnableFlyingMode`)

When player mounts dragonfly:

```lua
local function EnableFlyingMode(inst, enable)
    if enable then
        inst:AddTag("flying")
        inst.components.drownable.enabled = false
        inst.Physics:SetCollisionMask(
            COLLISION.GROUND,
            COLLISION.CHARACTERS,
            COLLISION.GIANTS
        )
    else
        inst:RemoveTag("flying")
        inst.components.drownable.enabled = true
        inst.Physics:SetCollisionMask(
            COLLISION.WORLD,
            COLLISION.OBSTACLES,
            COLLISION.SMALLOBSTACLES,
            COLLISION.CHARACTERS,
            COLLISION.GIANTS
        )
    end
end
```

**Key**: Removes water drowning and ground collision while airborne. Dragonfly inherits `MakeFlyingGiantCharacterPhysics` (line 691), making both mount and rider no-clip through obstacles.

## 3. Stategraph Modifications

### 3.1 Boss Stategraph Extension

**File**: `postinit/stategraphs/SGdragonfly.lua:1–228`

Vanilla dragonfly is **stationary**. This mod adds:

```lua
AddStategraphPostInit("dragonfly", function(sg)
    -- Growth states
    sg.states.grow_pre = State{
        name = "grow_pre",
        tags = {"busy"},
        onenter = function(inst)
            inst.components.locomotor:StopMoving()
            inst.Physics:Stop()
            inst.AnimState:PlayAnimation("grow_pre")
        end,
    }
    
    sg.states.grow_pst = State{...}
    
    -- Hunger behavior
    sg.states.hungry = State{
        name = "hungry",
        tags = {"busy"},
        onenter = function(inst)
            inst.components.locomotor:StopMoving()
            inst.Physics:Stop()
            inst.AnimState:PlayAnimation("hungry")
            inst.components.timer:StartTimer("play_hungry_cd", 30)
            inst:ShowHungryIcon()
        end,
    }
    
    -- Override idle to play hungry animation when starving
    local idle_onenter = sg.states.idle.onenter
    sg.states.idle.onenter = function(inst, ...)
        if inst:HasTag("dragonfly_mount") then
            local hungry = inst.components.hunger and inst.components.hunger:GetPercent() <= 0
            if hungry and not inst.components.timer:TimerExists("play_hungry_cd") then
                inst.sg:GoToState("hungry")
                return
            end
        end
        return idle_onenter(inst, ...)
    end
end)
```

**Pattern**: Uses `AddStategraphPostInit()` to inject new states and **override vanilla idle behavior without breaking it**.

### 3.2 Recall/Summon States

**File**: `SGdragonfly.lua:159–227`

```lua
sg.states.bell_summon = State{
    name = "bell_summon",
    tags = {"flight", "busy", "noelectrocute"},
    
    onenter = function(inst)
        inst.AnimState:PlayAnimation("walk_angry", true)
        inst.Physics:SetMotorVelOverride(0, -11, 0)  -- Move upward
        inst.DynamicShadow:Enable(false)
    end,
    
    onupdate = function(inst)
        inst.Physics:SetMotorVelOverride(0, -15, 0)
        local x, y, z = inst.Transform:GetWorldPosition()
        if y < 0.5 or inst:IsAsleep() then
            inst.Physics:ClearMotorVelOverride()
            inst.sg:GoToState("idle", {softstop = true})
        end
    end,
}
```

**Teleport-by-animation**: The summon state uses `SetMotorVelOverride()` to manually move the entity upward (negative Y = up), then clears it when y reaches ground. No actual portal—just velocity manipulation.

**Locomote event hijack** (SGcommon.lua:119–140):

```lua
local locomote_fn = sg.events.locomote.fn
sg.events.locomote.fn = function(inst, data)
    local mount = inst.replica.rider:GetMount()
    if not mount or not mount:HasTag("dragonfly_mount") then
        return locomote_fn(inst, data)
    end
    
    -- Intercept state transitions
    local _GoToState = inst.sg.GoToState
    inst.sg.GoToState = function(self, state, ...)
        if state == "run_start" then
            state = "dragonfly_mount_run_start"  -- Custom state
        elseif state == "run_stop" then
            state = "dragonfly_mount_run_stop"
        end
        return _GoToState(self, state, ...)
    end
    
    locomote_fn(inst, data)
    inst.sg.GoToState = _GoToState
end
```

**Technique**: Temporarily override `sg.GoToState()` inside the event handler to redirect state transitions. Very elegant—avoids duplicating the entire locomote logic.

### 3.4 Attack Modification

**File**: `postinit/stategraphs/SGcommon.lua:21–94`

```lua
table.insert(attack_timeline, TimeEvent(12 * FRAMES, function(inst)
```

## 4. Prefab Override Pattern

### 4.1 Vanilla Dragonfly PostInit

**File**: `postinit/prefabs/dragonfly.lua:1–12`

```lua
local AddPrefabPostInit = AddPrefabPostInit

GLOBAL.setfenv(1, GLOBAL)

AddPrefabPostInit("dragonfly", function(inst)
    if not TheWorld.ismastersim then return end
    
    if inst.components.lootdropper then
        inst.components.lootdropper:AddChanceLoot('dragonfly_bell_blueprint', 1.00)
        inst.components.lootdropper:AddChanceLoot('saddle_dragonfly_blueprint', 1.00)
        inst.components.lootdropper:AddChanceLoot('dragonfly_mount_egg', 1.00)
    end
end)
```

**Clean pattern**: Only adds loot drops to vanilla dragonfly, not a full replacement. The **custom dragonfly_mount prefab is separate** (`scripts/prefabs/dragonfly_mount.lua`), spawned from egg.

### 4.2 Composition over Mutation

Instead of modifying vanilla dragonfly in place:

1. **dragonfly_mount.lua** (line 675–910): Complete new prefab definition
   - Sets up `dragonfly_mount_brain` (custom AI)
   - Adds `rideable`, `hunger`, `growable`, `locomotor` components
   - Uses `MakeFlyingGiantCharacterPhysics()` for flight physics

2. **dragonfly_mount_egg.lua**: Spawns a baby dragonfly_mount, which grows through stages

3. **Vanilla dragonfly** remains unmodified (only loot added)

**Advantage**: Avoids conflicts with vanilla; easy to enable/disable; supports multiple mount variants.

## 6. Key Technical Insights for Tu-Tiên Mod

### 6.1 Dynamic Boss AI (for realm bosses/spirit enemies)

**Pattern used here**: Behavior tree with **target memory** tracking opponent attack patterns.

```lua
inst.targetmem = {
    target = target,
    sgname = current_state_name,
    timeinstate = time_in_state,
    distsq = distance_squared,
    danger_range_sq = estimated_hit_range,
    attacking = is_attacking,
    invincible = has_invincibility,
}

-- Update every frame via WatchTargetCombat
inst:DoPeriodicTask(0, WatchTargetCombat)
```

**For cultivation realms**: Track player's cultivation stage, combo state, chi depletion—then adjust monster difficulty dynamically.

### 6.2 Mount/Rideable Setup Checklist

1. **Rideable component** with `SetSaddleable(true)` + custom test
2. **Follower component** (for bell/taming ownership)
3. **Locomotor with flight pathcaps** (ignorewalls, allowocean)
4. **Flying tag** + Physics collision override
5. **Stategraph with custom rider states** (run_start/run_loop)
6. **Player postinit**: Enable flying mode, disable drowning, redirect locomote events

Based on dragonfly mount patterns:

### 6.4 Stategraph Hijacking Pattern

Use in boss transformations / cultivation breakthroughs:

```lua
AddStategraphPostInit("dragonfly", function(sg)
    -- Inject new state without touching vanilla code
    sg.states.transform_breakthrough = State{
        name = "transform_breakthrough",
        tags = {"busy", "nointerrupt"},
        onenter = function(inst) ... end,
    }
    
    -- Override existing state handler
    local old_idle = sg.states.idle.onenter
    sg.states.idle.onenter = function(inst, ...)
        if inst:HasTag("in_breakthrough") then
            inst.sg:GoToState("transform_breakthrough")
            return
        end
        return old_idle(inst, ...)
    end
    
    -- Hijack event to redirect transitions
    local old_locomote = sg.events.locomote.fn
    sg.events.locomote.fn = function(inst, data)
        if inst:HasTag("cultivating") then
            inst.components.locomotor:Stop()
            return
        end
        return old_locomote(inst, data)
    end
end)
```

## Summary

1. **Brain/AI**: Custom behavior tree tracks opponent attack patterns in real-time (`targetmem`), decides evasion/chase via distance & cooldown. Pauses when mounted.

2. **Mount**: Separate `dragonfly_mount` prefab (not vanilla override) with rideable/follower/hunger/growable. Custom rider test enforces saddle + fed state. Player gains flying tag + collision bypass.

3. **Stategraph**: New states (grow, hungry, recall) injected via PostInit. Locomote event intercepted to reroute run_start → dragonfly_mount_run_start. Attack timeline extended with fire damage checks.

4. **Override pattern**: Use `AddPrefabPostInit()` / `AddStategraphPostInit()` for safe extensions. Separate new prefab rather than mutating vanilla. Compose behavior trees instead of flat state machines.

5. **Flying template**: Dragonfly's velocity override + physics setup + rideable + stategraph hijacking provide a working blueprint for flying sword travel (phi kiếm).
