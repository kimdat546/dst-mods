## Ghi chú
- "象鼻每三天收获象鼻*1" — chữ 象鼻 đầu câu là lỗi gõ của tác giả (đúng ra 象屋); dịch "Nhà voi".
- 龙蝇 / 装甲熊獾 dùng tên mod trong glossary (Long Nhặng / Hùng Hoan Trang Giáp, theo 龙蝇巢穴, 装甲熊獾巢穴) thay vì tên DST gốc (Dragonfly / Gấu Lửng Bọc Giáp) cho khớp nhãn công trình.
- Nguyên liệu gốc DST theo bản game: 牛毛 = Lông bò, 牛角 = Sừng Bò Lai, 羊奶 = Sữa Dê Điện, 伏特羊角 = Sừng Vôn Dương, 象鼻 = Vòi voi, 鳞片 = Vảy, 纯粹辉煌 = Quang Thạch Tinh Khiết. Ngọc theo glossary (Hoàng/Lục/Cam/Hồng/Lam/Tử Bảo Thạch).
- 浣猫 dịch "mèo gấu trúc" theo glossary 浣猫树屋 = Nhà Cây Mèo Gấu Trúc (bản game gọi Catcoon là "Mèo Trúc").
